# Interview Practice Kit

This folder is intentionally separate from the main engineering docs so it is easy to open directly on GitHub before interviews.

## Files

- `system-design-walkthrough.md`: End-to-end architecture explanation in interview format.
- `rag-agents-memory-cheatsheet.md`: Quick revision notes for RAG, agents, memory, retrieval, and evaluation.
- `faang-practice-questions.md`: Practice questions and strong answer outlines.
- `module-1-foundation-qa.md`: Detailed Q&A for the initial platform foundation.

## How To Use

1. Read the system design walkthrough first.
2. Review the cheatsheet before calls.
3. Practice the FAANG-style questions out loud.
4. Use the module Q&A for deeper follow-up preparation.
